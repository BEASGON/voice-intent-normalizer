# 谐音狐中文 README 品牌设计

## 目标

将仓库首页从英文技术说明调整为面向中文用户的产品型介绍，同时保持所有能力描述与当前 `v0.1.0` 实现一致。中文昵称使用“谐音狐”，英文项目名继续使用 `Voice Intent Normalizer`。

## 命名体系

- 中文昵称：谐音狐
- 中文全称：谐音狐 · 中文语音意图纠错技能
- 英文名称：Voice Intent Normalizer
- 英文简称：VIN
- 主口号：你负责说，谐音狐负责听懂
- 辅助表达：让 AI 听懂你，不被谐音带偏

昵称负责记忆与传播；“中文语音意图纠错技能”负责准确说明功能，避免用户误以为项目只处理谐音字。

## 文档结构

根 `README.md` 使用简体中文，现有英文内容保存为 `README.en.md`。中文 README 前半部分依次包含：

1. 品牌首屏与一句话定位；
2. 真实误识别示例；
3. 用户痛点与错误执行风险；
4. 重复解释和返工造成的无效 Token 消耗；
5. 现有方法的局限；
6. 谐音狐的处理位置与四层词库；
7. `apply`、`ask`、`keep` 三种决策；
8. 本地优先与提交后纠错边界。

后半部分保留可执行的快速开始、平台兼容性、学习命令、故障排查、开发和许可证信息。

## 真实性边界

- 不宣称实时修改语音输入框；项目在消息提交后工作。
- 不宣称读取所有会话历史；判断依据是本次输入与已配置词库。
- 不宣称从普通对话自动学习；个人和项目映射必须明确创建。
- 不宣称每次调用必然节省 Token；只说明减少误解、重复说明、错误生成和任务返工带来的无效消耗。
- 不宣称 `v0.1.0` 自动联网更新热点词；热点快照随审核版本发布。
- 高影响歧义必须优先询问，而不是擅自替换。
