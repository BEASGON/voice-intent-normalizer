# Changelog

All notable changes to this project are documented here.

## 0.1.1 - 2026-08-24

- Introduces the 谐音狐 brand and a Chinese-first README while preserving the
  complete English documentation.
- Expands real voice-input pain points, Token-saving benefits, and platform
  guidance for Codex, OpenClaw, WorkBuddy, and generic desktop agents.
- Fixes cross-platform coverage source normalization and improves concurrent
  installation diagnostics.

## 0.1.0 - 2026-08-14

- Initial release of local Chinese voice-intent normalization.
- Adds explicit personal and project learning, validated hotword updates, and
  correction receipts for submitted text.
- Adds Codex, OpenClaw, WorkBuddy, and generic-host packaging paths with
  documented capability boundaries.
